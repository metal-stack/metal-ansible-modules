# metal

Dynamic inventory for metal-stack

## Synopsis

- Generates an inventory of machines managed by the metal-api.

- Returns machines that are tagged with the `ci.metal-stack.io/manager=ansible` label.

- The inventory plugin can be further configured with machine filters using a config file.


## Requirements

- [metal-python](https://pypi.org/project/metal-python/)
